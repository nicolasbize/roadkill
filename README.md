## Welcome to Roadkill!

This is a fun fast-paced racing/fighting game similar to Road Rash which uses pseudo 3d graphics, 8 bit soundtracks and can be played using a controller, a mobile device or your keyboard.

Play the game: https://gadgaming.itch.io/roadkill

The game contains 4 different tracks (USA, Italy, Japan, France), 5 unlockable bikes, several attack types - all rendered within a tiny 64x64px canvas.

Hope you have as much fun playing it as we had creating it!
